PROBAR SPORTSTATS EN EL IPHONE DESDE WINDOWS CON XTOOL
======================================================

Que se agrego al proyecto para xtool
------------------------------------
- Package.swift: xtool no usa .xcodeproj, usa SwiftPM. Este manifiesto compila
  Frontend/ y Backend/ como la app, en modo Swift 5 (igual que el proyecto Xcode)
  y para iOS 17.
- xtool.yml: con el mismo bundle id (cl.ninaspro.sportstats).
- .gitignore: ignora la carpeta xtool/ que se genera al compilar.
- Assets.xcassets queda fuera de Package.swift porque en Linux no se puede
  compilar. El icono (AppIcon.png, generado con scripts/make_icon.py) lo usa
  el build de Xcode, y xtool.yml lo apunta con "iconPath".
- SportStats.xcodeproj queda igual y sigue sirviendo en Mac.

- .github/workflows/build-ipa.yml: compila la app en un Mac de GitHub Actions.

IMPORTANTE: "xtool dev" NO compila esta app. Las macros de SwiftData (@Model,
@Attribute, @Relationship) solo se pueden expandir con Xcode en Mac; en Linux
falla con "plugin for module 'SwiftDataMacros' not found". Por eso la app se
compila en GitHub Actions y en Ubuntu solo se firma e instala con
"xtool install" (ver "PROBAR LA APP EN EL IPHONE").


PASOS EN WINDOWS (una sola vez)
-------------------------------

1. Instalar Ubuntu en WSL (PowerShell como administrador):

     wsl --install -d Ubuntu

2. Conectar el iPhone a Ubuntu a traves de Windows:
   NO usar usbipd: con iPhones nuevos se queda pegado en "[Connecting]" o da
   "muxError" (usbmuxd: "message was too large"). En su lugar Windows maneja
   el iPhone y Ubuntu se conecta a el por red (puerto 27015).
   - Instalar "Apple Devices" desde la Microsoft Store, conectar el iPhone por
     cable, abrir Apple Devices y aceptar "Confiar" en el iPhone.
   - Comprobar en PowerShell:  netstat -ano | findstr 27015   (debe decir LISTENING)
   - En PowerShell como administrador (una sola vez):

       New-NetFirewallRule -DisplayName "WSL usbmuxd" -Direction Inbound -InterfaceAlias "vEthernet (WSL)" -Protocol TCP -LocalPort 27015 -Action Allow
       netsh interface portproxy add v4tov4 listenaddress=<IP> listenport=27015 connectaddress=127.0.0.1 connectport=27015

     <IP> es la de Windows vista desde Ubuntu: en Ubuntu, "ip route list default"
     (la que va despues de "via", por ejemplo 172.21.64.1). Si cambia despues de
     reiniciar, repetir el netsh con la IP nueva.

3. Dentro de Ubuntu:
   - Instalar Swift siguiendo https://swift.org/install/linux (con swiftly).
     Si "swift --version" dice que falta libncurses.so.6 u otra libreria:

       sudo apt install -y build-essential libncurses-dev libedit2 libcurl4-openssl-dev libxml2-dev libsqlite3-0 libpython3-dev libz3-dev zlib1g-dev pkg-config gnupg2 tzdata unzip

   - Instalar las herramientas del iPhone y zip (xtool lo necesita al instalar):

       sudo apt install -y libimobiledevice-utils zip unzip

   - Apuntar a Windows para hablar con el iPhone (una sola vez):

       echo 'export USBMUXD_SOCKET_ADDRESS="$(ip route list default | awk "{print \$3}"):27015"' >> ~/.bashrc
       source ~/.bashrc
       ideviceinfo -k DeviceName     (debe mostrar el nombre del iPhone)

4. Descargar Xcode 27 (.xip) desde
   https://developer.apple.com/download/all/?q=Xcode
   (en el navegador, iniciando sesion con el Apple ID).

5. Instalar xtool (en Ubuntu):

     curl -fL "https://github.com/xtool-org/xtool/releases/latest/download/xtool-$(uname -m).AppImage" -o xtool
     ls -lh xtool       (debe pesar ~55M; si pesa 0, repetir la descarga)
     chmod +x xtool && sudo mv xtool /usr/local/bin/
     sudo apt install -y libfuse2t64     (en Ubuntu viejo: libfuse2)
     xtool --help
     xtool setup

   - xtool setup primero pide el modo de inicio de sesion:
       0: API Key  -> solo con cuenta de desarrollador pagada (US$99/ano)
       1: Password -> sirve con un Apple ID gratuito
     Con Apple ID gratuito elegir 1. Usa APIs privadas de Apple, asi que conviene
     usar un Apple ID secundario.
   - Despues pide la ruta del .xip, por ejemplo:
       /mnt/c/Users/Javier Catalán/Downloads/Xcode_27.0.xip
   - Para confirmar que funciono:

       swift sdk list     (debe mostrar "darwin")


PROBAR LA APP EN EL IPHONE
--------------------------
1. Hacer git push a main. GitHub compila solo (tambien se puede lanzar a mano
   en GitHub -> Actions -> "Compilar IPA" -> Run workflow). Tarda unos minutos.
2. Cuando termine (check verde), abrir esa ejecucion y descargar el artefacto
   "SportStats-ipa" (hay que tener sesion iniciada en GitHub). Baja un .zip.
3. En Ubuntu, con el iPhone conectado, Apple Devices abierto y el iPhone
   desbloqueado:

     cd ~
     unzip -o "/mnt/c/Users/Javier Catalán/Downloads/SportStats-ipa.zip"
     xtool install SportStats.ipa     (firma con tu Apple ID e instala)

- La primera vez, activar en el iPhone:
    Ajustes -> Privacidad y seguridad -> Modo de desarrollador
- Luego confiar en el Apple ID:
    Ajustes -> General -> VPN y gestion de dispositivos
- Con un Apple ID gratuito la app dura 7 dias; para renovarla volver a correr
  "xtool install SportStats.ipa".
- Si se cambia el bundle id en xtool.yml, cambiarlo tambien en
  scripts/gen_xcodeproj.py.


PROBLEMAS COMUNES
-----------------
- "ideviceinfo" no encuentra el iPhone: revisar que Apple Devices este abierto
  y vea el iPhone, que "netstat -ano | findstr 27015" diga LISTENING, y que la
  IP del netsh sea la de "ip route list default" (puede cambiar al reiniciar).
- Referencia del metodo de conexion:
  https://github.com/xtool-org/xtool/issues/19#issuecomment-2898986718
- Errores al compilar en GitHub Actions: abrir la ejecucion en la pestana
  Actions y revisar el paso "Compilar".
